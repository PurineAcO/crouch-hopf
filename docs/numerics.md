# Crouch-Py

二维可压缩定常基流的全局线性稳定性分析，支持层流与 Spalart–Allmaras（SA）模型。输入为 O 型网格及基流，输出为广义特征矩阵和扰动模态。

## 模型选择

装配时必须显式指定模型：

```sh
uv sync --frozen
uv run python crouch/solvemain.py /path/to/case --model laminar --alpha 0
uv run python crouch/eigmain.py /path/to/case --sigma-imag 0.73 --k 12
```

SA 基流使用 `--model sa`，例如 NACA 0012 的 SA-RANS 稳定性分析。两端必须使用同一物理模型；该接口尚不构成对 NACA 0012 算例的验证。`--alpha` 可取 0、0.2、1，分别为论文的中心、混合与迎风格式。圆柱临界点对照论文图 3 时使用 0。

| 设置 | 层流 `laminar` | 湍流 `sa` |
| --- | --- | --- |
| 特征变量 | ρ、u、v、T | ρ、u、v、T、ν̃ |
| 湍流黏度 | 严格为零 | μt=ρν̃fv1 |
| SA 输运、源项 | 不装配到最终算子 | 保留 |
| 基流 ν̃ | 必须全部为零 | 必须有限、非负 |

局部雅可比共用五分量顺序；层流在验证 SA 列与流动方程无耦合后，提取四变量矩阵。保留第五分量的局部结构用于两种模型共用重构与边界代码。两种模型均冻结基流分子黏度，暂不包含 Sutherland 温度导数。

## 输入与输出

每个算例目录包含：

- `ransdata.txt`：首行为列名，至少含 `s n x y sad vol rho u v T miubl`；`miubl` 是 SA 工作变量 ν̃，单位 m²/s。周向和径向索引从 1 开始。
- `edge.txt`：首行为 `type s n id c1_s c1_n c1_id c2_s c2_n c2_id nx ny mx my`，类型为 `NS` 或 `WE`，法向含面长。
- `input/parameters.json`：`nt`、`nr`、`D_m`、`U_m_s`、`rho_kg_m3`、`T_K`、`mu_Pa_s`；必须记录 `model`，装配时核对其与 `--model` 一致，缺失即报错。SA 还必须记录 `sa_formulation=crouch-2007`，对应包含 C5 项的重新计算基流。

物性和 SA 常数在根目录 `config.json`。模型仅在命令行通过必填的 `--model` 选择；根配置不再重复保存模型。输出 `S.npz`、`T.npz` 和 `assembly.json`；特征值求解读取装配记录的模型并校验矩阵维数。重复装配同一目录会覆盖矩阵，应为不同工况使用独立目录。

`eigmain.py` 保留边界代数行，求解完整稀疏广义特征方程 `Sq=λTq`；移位反演算子为 `(S−σT)⁻¹T`，采用 `exp(λt)` 约定。输出增长率 `Re(λD/U)`、角频率 `Im(λD/U)`、`St`、完整方程相对残差，以及各模态和量纲尺度。边界环上的相邻未知量相互耦合，不做逐单元边界消元。求解同时报告全方程残差和独立的边界代数约束残差。

## 精确反射投影与排序

`eigmain.py --wake-symmetry` 是可选的计算降维，默认仍求解完整描述子矩阵。该选项支持偶数 `nt` 的 O 型网格，反射映射为每一径向环内的 `s -> nt-1-s`（这里 s 从零开始），对应物理平面 y=0。反对称分支中 ρ、u、T、ν̃ 改变符号，v 保持符号。每对单元用权重 `1/sqrt(2)` 构造稀疏正交基 P，满足 `PᵀP=I`；P 的行覆盖全部 `nr*nt*nvar` 未知量，包含两个边界环。

先做变量与时间缩放 `A=(D_m/U_m_s) D⁻¹ S D`、`B=D⁻¹ T D`，再求解 `Ar=PᵀAP`、`Br=PᵀBP`。移位反演为 `(Ar−σBr)⁻¹Br`，由 `λ=σ+1/μ` 恢复特征值。输出模态为完整缩放变量 `x=Pz`，物理扰动为 `Dx`，与未投影时的输出约定相同。这不是逐单元边界消元，也不会修改 法向对齐三点模板的径向先验、二维矩条件或任何物理系数。

投影前检查单元坐标、体积、壁面距离、基流变量及 NS/WE 面的连接、法向和中点。还分别检查 A、B 与反射算子的交换性：每一行的 L1 缺陷除以该行及镜像行范数的较大者，最大相对缺陷不得超过 `1e-10`。逐行检查避免大守恒方程掩盖小边界方程的不对称；任何检查失败都拒绝投影，不对输入或矩阵进行对称化。

恢复到完整网格后，用完整 A、B 重新计算 `||Ax−λBx||/(||Ax||+||λBx||)`，并独立检查全部零质量行的代数约束误差；两者均须有限且不超过 `1e-6`。正交投影只保留反对称谱分支，不代表已经检查另一对称分支的稳定性。

`--ordering COLAMD` 是默认稀疏 LU 排序；另支持 `--ordering MMD_AT_PLUS_A`。排序改变填充量及浮点舍入，不改变离散方程，但 MMD 并不保证更低填充。在同一 Re47、128×96、四变量矩阵上，COLAMD 完整/反对称求解的峰值 RSS 分别为 1.483/0.548 GiB，SuperLU 分配的因子条目数为 71.94M/20.52M。五个共同反对称特征值相差不超过 `1.2e-14`，提升后的最大完整残差为 `8.93e-10`。MMD 反对称试算超过 3.36 GiB 和 220 秒后中止，没有取得完整的因子计数或特征对结果。这是一份单算例计算基准，不是更细网格或 125D 远场的内存保证。

求解 JSON 保留原有模型、特征值残差和计时字段，并增加 `ordering`、`full_dimension`、`solve_dimension`、`reflection_errors`、`reflection_input_errors` 和 `peak_rss_bytes`。`factor_nnz` 采用 SuperLU 的已分配因子存储条目数（含预留槽），由 `factor_nnz_definition` 明确标识；它不再通过复制 L、U 来统计数学非零项，以避免诊断本身增加大块内存。`peak_rss_bytes` 是整个求解进程的峰值常驻内存，不是仅 LU 阶段的内存。该字段在原生 Windows 等缺少 `resource` 模块的平台上为 JSON `null`，不阻止求解，也不引入额外依赖；Linux 的计算方式和字节单位保持不变。

这些求解选项不改变 `thermodynamics` 或 `sa_formulation` 的物理版本要求。旧基流仍须按下述热力学与 SA 版本约定重新计算；不能用新排序或投影代替基流版本校验。

完整 `pytest` 测试包含独立符号源项/黏性系数、物理多项式边界再现、斜交非均匀网格的解析块作用、完整耦合描述子谱和 CLI。`tests/test_reflection_solver.py` 另覆盖四/五变量正交基、耦合边界、两种排序、非对称输入与矩阵拒绝、恢复后的完整约束及 CLI 输出。测试不对物理通量做数值差分或复数步长求导。

## 上风零速判定与反射一致性

对流面的零速阈值采用 `64 eps ||m|| max(|U_left|, |U_right|, a_left, a_right)`，其中 `a=sqrt(gamma R T)`。低于阈值时取 `sign=0`。仅用局部速度作尺度，会在壁面或驻点附近把约 `1e-14`–`1e-13 m/s` 的基流横向舍入误差判为非零输运；在自身映射到自身的 WE 对称轴面上，这会选择完整的单边模板，产生 O(alpha) 的反射缺陷。声速尺度避免该问题，保留原来的面度量、重构权重、通量系数和 64-eps 系数。

该修正已应用，不放宽反射或特征残差检查，也不通过对矩阵做对称化来隐藏误差。N80/N160 的原 alpha=0.2/1 矩阵反射缺陷约为 0.16/0.65；只修正零速选择后，缺陷恢复到约 `3.2e-14`/`2.4e-13`。N80 重新装配的 alpha=0 层流 S、T 与已有矩阵完全一致，包括逐位相同的数值；现有主算例矩阵及 边界权重未被覆盖或修改。独立目录中实际 alpha=0.2/1 投影求解的最大提升后完整残差分别为 `7.72e-11` 和 `4.98e-11`。

alpha=0 时四个流动方程的权重不依赖 sign，因此层流中心矩阵保持完全不变。SA 的第五行在所有 alpha 下均为一阶迎风，它的零速选择也会得到修正，包括 alpha=0；这不应被误述为 SA 整个中心矩阵完全不变。`tests/test_upwind_reflection.py` 保留 38 个参数化回归检查，覆盖 WE/NS 反射、两种输运方向、层流/SA、三种 alpha、含绝对速度噪声的对称轴面及近驻点零速极限。参考使用解析系数与反射恒等式，不对物理通量做数值求导。

## 方法与代码

- `convect.py`：Crouch 等（2007）式 3.1.10–19，分别重构系数矩阵与扰动，再求通量；SA 对流采用一阶迎风。式 3.1.14 印刷式重复使用 `1-sign`，实现按迎风方向将左权重写为 `1+sign`。
- `linearization.py`、`viscous.py`：显式解析黏性及 SA 源项系数、中心黏性离散。物理通量不采用数值求导或复数步长求导；测试使用独立符号表达式核对解析系数。
- `boundary.py`、`formmat.py`：边界约束、周期及虚单元映射、稀疏矩阵装配。
- `models.py`、`solvemain.py`、`eigmain.py`：模型校验、装配入口、特征求解。

扰动边界施加在首末单元中心环。基流离散与稳定性离散不同，特征残差小不代表空间误差小。旧边界版本的圆柱扫描不能作为本版的验证结果；本版仍需重新检查中性点和网格收敛。

```sh
uv run ruff check crouch tools tests
uv run ruff format --check crouch tools tests
OPENBLAS_NUM_THREADS=2 uv run pytest -q
```

文献：J. D. Crouch, A. Garbaruk, D. Magidov, *Predicting the onset of flow unsteadiness based on global instability*, J. Comput. Phys. 224 (2007), 924–940. [DOI](https://doi.org/10.1016/j.jcp.2006.10.035)。

## 解析线性化与边界约定

保留原版局部 5×5 系数块、13 邻点离散模板与全局稀疏矩阵装配。黏性应力使用 Stokes 假设，导热系数为 `Cp(μ/Pr+μt/Prt)`；冻结分子黏度扰动，但保留 `μt=ρν̃fv1` 的密度和工作变量响应。SA 扩散系数为 `(μ+ρν̃)/σ`，源项逐项包含产生、破坏、`ρCb2|∇ν̃|²/σ` 与 `−C5ρν̃² S²/a²`。这里 `C5=3.5`，`S²=2ux²+2vy²+(uy+vx)²`。不添加保守形式中不存在的密度梯度源项。

不对 Ω 或修正涡量 S̃ 施加下限；保留论文的 `r≤10`。Ω=0 处绝对值没有唯一的线性导数，采用对称线性化系数零；S̃=0 且 ν̃非零的孤立奇点，与基流端一致采用 r 的正侧饱和值及其零响应。负大 r 用倒数恒等变换计算，避免高次幂溢出。这些约定不构成修改产生项的涡量限幅。壁面距离在线性化中固定。

边界法向导数在物理平面上用七个邻点重构二维二次多项式，再取 `n·∇`。以三点径向差分作为先验，并用全部二维矩条件修正权重；正交网格恢复原法向三点式，斜交网格仍满足二维再现性。单纯最小范数七点权重会改变正交网格远场离散，在圆柱临界点附近已观察到明显偏移，因此不作为当前边界环的默认选择。SVD 缩放处理两个方向的尺度差异；矩阵秩不足时明确报错，不能退回一维投影。该方法在满秩的斜交模板上精确重构二次多项式，避免将切向变化误判为法向变化。约束仍施加在首末单元中心环，几何边界位置误差须通过网格研究评估。

远场使用统一外法向和论文不变量 `I±=un±2a/(γ−1)`；解析扰动为 `δun±a δT/((γ−1)T)`。它们在非零熵扰动下不等同于 Euler 左特征向量。按 `un±a` 判断声学信息方向：亚声速入流指定 I−、切向、熵和 SA 扰动，外推 I+；亚声速出流仅指定 I−。外推使用邻点各自的基流系数与中心法向。零速信息按指定值处理。

论文式 (3.1.14) 左侧迎风权重重复印为 `1−sign`，实现使用 `1+sign`；式 (2.2.5) 的 C5 末项梯度按应变率定义使用 vy。热传导保留能量量纲要求的 Cp。配置中的 Cv 修正为 717.625，使 Cp−Cv=R、Cp/Cv=γ，与基流端热力学关系一致。时间约定与论文 `exp(−iωt)` 的对应关系为 `λ=−iω`。

基流参数须记录 `thermodynamics` 中的 R、Cp、Cv、gamma，并与当前配置一致；Purine 场文件须带 `thermo=ideal-air-cv717625-v1` 标记。旧版 Cv=717.645 的层流及 SA 基流均需重新计算，不能仅修改标签。

这些 alpha>0 的低残差只验证离散特征方程的求解精度，不能证明物理尾迹分支有效。标量均值速度选边对逆向声学分支可能产生反耗散；远场模态污染及 Table 1 的物理对照尚待研究。当前完成范围和限制见[验证记录](validation.md)。
