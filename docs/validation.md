# Crouch 2007 修复验证与研究状态

本次修复将物理系数改为显式解析线性化，并保留完整的边界代数约束。软件回归通过不等同于论文网格无关性复现；以下圆柱数据是已停止计算的阶段结果，未补填缺失结果。

## 可重复的软件验证

```sh
uv sync --frozen
OPENBLAS_NUM_THREADS=2 uv run --frozen pytest -q
uv run --frozen ruff check .
uv run --frozen ruff format --check .
```

当前测试共205项，覆盖：

- 独立符号推导的黏性、热传导、SA产生/破坏、梯度平方及C5系数；不使用物理通量有限差分或复数步长。
- 二维二次多项式的边界法向导数、偏斜与高纵横比几何、法向对齐时的原三点极限，以及Riemann不变量的解析导数与入出流分配。
- 斜交网格上的解析块作用、含耦合边界的广义特征方程、恢复后完整方程及边界残差。
- 层流/SA反射投影、非对称输入拒绝、驻点附近迎风选边、排序选项、CLI及物性元数据检查。

Re45/49的物理分支来自24模态搜索；原窄搜索未捕获它，不能将编号0或增长率最大者自动视为物理模态。分支选择结合近尾迹复速度相关性、远场幅值和参数连续性。N80两点线性中性点估计为Re≈46.27028。

Re60、alpha=0的论文Table 1对照值分别为N80：频率0.7614、增长率0.0342；N160：频率0.7434、增长率0.0425。当前N160相对差异约为频率−0.193%、增长率−1.545%。N80基流绝对更新容差从1e-8加严至1e-10后，增长率变化−6.4474e-7、频率变化+1.0544e-6；该检查不能替代细网格收敛验证。

此前128×96、外节点半径30D的Re43/45/47/49系列给出中性点约47.19221。它与本表的网格和外域均不同，不应直接将差别归因于某一个修复。

## 尚未完成及使用条件

- 全部CFD计算已按用户要求停止。Re60 N240基流、Re45/49 N160基流尚未完成；没有最终网格无关性结论。N320已取消。
- 外域125D→200D只检查了网格扩展保留旧节点，尚未完成谱验证。
- 边界仍在首/末层单元中心施加。二维二次准确的导数不能消除边界位置误差；尚未定量确认其对特征值偏差的贡献。
- alpha=0.2/1的部分离散特征对虽然残差小，但物理尾迹分支未通过验证。零速舍入选边修复解决反射缺陷，并不证明迎风离散已复现论文Table 1。
- 使用匹配的Purine基流实现：热力学参数为R=287.05、Cp=1004.675、Cv=717.625、gamma=1.4；SA基流还须包含C5项并标记`sa_formulation=crouch-2007`。旧场须重新计算，不能只改标签。
- SA有独立完整耦合谱回归，最大特征对残差约7.09e-10；这是代数验证，不是Re60层流物理验证。
